# TUU Quantum Validation Protocol

## Purpose

Define a reproducible boundary between classical preprocessing, analytical estimates, controlled simulation, and real quantum-hardware measurements.

This document does **not** claim that Reimei/H2 jobs have been executed. Hardware-specific values must be independently verified before being promoted from assumptions to measured inputs.

## Evidence classes

| Class | Meaning | May support experimental claim? |
|---|---|---|
| `INPUT` | User/vendor/documented parameter used as an assumption | No |
| `ANALYTICAL` | Derived estimate from explicit equations | No |
| `SIMULATION` | Result generated by a reproducible simulator/model | No |
| `EXPERIMENT` | Measurement returned by an identified QPU/backend | Yes, subject to reproducibility |

Every numerical result in a TUU report MUST carry one of these classes.

## Required experimental provenance

A hardware result is not accepted as `EXPERIMENT` unless the record contains:

- backend/system identifier;
- execution timestamp;
- circuit/ansatz version or immutable commit reference;
- qubit count actually used;
- circuit depth and gate counts;
- shots and measurement protocol;
- noise/error assumptions, if any;
- optimizer and stopping criteria;
- random seed where applicable;
- raw or losslessly preserved measurement output;
- SHA-256 hash of preserved artifacts;
- baseline definition;
- software/toolchain versions;
- explicit separation from simulated results.

## TUU benchmark matrix

The minimum comparison should include:

1. noiseless classical simulation;
2. noisy classical simulation using measured/declared hardware error parameters;
3. baseline model with identical optimizer budget;
4. hardware execution, when authorized and available.

The same observable definitions, stopping criteria, and statistical treatment must be used across comparable arms.

## Core observables

Do not assume that a stable energy plateau proves topological protection. Measure independently:

- energy expectation and variance;
- convergence iterations and wall time;
- circuit fidelity or an explicitly defined proxy;
- long-range correlation observable with a predefined estimator;
- error-bar/confidence interval from repeated shots/runs;
- sensitivity to controlled noise or calibration drift;
- baseline-relative residual error.

A claim of `quantum advantage` requires a predefined baseline, equalized resource accounting, uncertainty estimates, and statistical evidence. Faster convergence alone is insufficient.

## Qubit accounting

For a target of `L` logical qubits, `A` ancillas, and physical-to-logical overhead `R`:

`physical_required = ceil((L + A) * R)`

The value of `R` must be stated rather than inferred from the total physical-qubit count. In particular, 56 physical qubits MUST NOT be described as 56 usable logical qubits.

## Fidelity/error model

For exploratory analytical estimates, a simple independent-gate approximation may be used only as a sensitivity model. For example, if `p1` and `p2` are error probabilities and `N1`/`N2` are gate counts:

`F_est ≈ (1-p1)^N1 * (1-p2)^N2`

This is an estimate, not a hardware fidelity measurement. Correlated errors, SPAM, transport, memory errors, crosstalk, compilation effects, and readout mitigation can invalidate the approximation.

## Stop conditions

The experimental claim is marked `INCONCLUSIVE` if any of the following occurs:

- hardware identity/configuration cannot be verified;
- provenance is incomplete;
- baseline is not reproducible;
- uncertainty intervals overlap the null result materially;
- the long-range observable is not independently defined;
- results depend on post-hoc parameter selection;
- required logical-qubit budget cannot be demonstrated.

A negative or inconclusive result is a valid outcome and must remain in the evidence record.

## TUU/Aurora execution boundary

```text
OSINT observations
      |
      v
classical normalization + evidence
      |
      v
Fugaku/classical preprocessing
      |
      +----> analytical estimates
      |
      +----> controlled simulation
      |
      v
circuit/ansatz artifact
      |
      v
authorized QPU execution
      |
      v
raw measurements + SHA-256
      |
      v
statistical analysis
      |
      v
baseline comparison
      |
      v
human review
```

AI remains `advisory_only`. No model output is itself evidence of a physical effect.
